About the Project

Guess a Number Game is a simple Java-based game where the player tries to guess a randomly generated number. The game provides hints after each attempt to help the player determine whether the entered number is higher or lower than the target number.

This project is designed to demonstrate basic Java programming concepts, including variables, loops, conditional statements, user input, and random number generation.

Features

- Random number generation
- User input
- Higher or lower hints
- Attempt counter
- Win detection
- Simple and interactive gameplay
- Option to play again

Technologies Used

- Java
- Java Scanner
- Random Number Generation
- Conditional Statements
- Loops

How to Play

1. Start the application.
2. The program generates a random number.
3. Enter your guessed number.
4. The game provides a hint:
   - Too High – Try a smaller number.
   - Too Low – Try a larger number.
5. Continue guessing until you find the correct number.
6. The game displays the number of attempts taken.

How to Run

Make sure Java JDK is installed on your computer.

Compile the Java file:

javac GuessNumberGame.java

Run the application:

java GuessNumberGame
